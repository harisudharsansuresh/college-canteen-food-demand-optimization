# College Canteen Food Demand Optimization Using Stochastic Optimization

## Project Overview

This project focuses on optimizing daily food preparation quantities in a college canteen under uncertain customer demand using stochastic optimization techniques.

The main objective is to determine the optimal number of meals to prepare to maximize expected profit while minimizing food wastage and customer shortages.

## Problem Statement

College canteens face uncertainty in daily customer demand. Preparing excess food leads to wastage, whereas preparing insufficient food results in unmet customer demand.

This project develops a stochastic optimization model to support better food preparation decisions under demand uncertainty.

## Objectives

- Model uncertain daily food demand using probability distributions.
- Develop a stochastic optimization model.
- Implement Monte Carlo simulation using Python.
- Determine the optimal daily food preparation quantity.
- Analyze expected profit, food wastage, and shortages.
- Compare stochastic and deterministic decision-making approaches.

## Methodology

1. Define possible demand scenarios and probabilities.
2. Generate simulated demand data.
3. Implement Monte Carlo simulation.
4. Evaluate different food preparation quantities.
5. Identify the quantity that maximizes expected profit.
6. Perform sensitivity and risk analysis.
